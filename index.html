Switching

The network layer moves packets from source to destination. A virtual circuit sets up a logical path first, reserves buffers and bandwidth, and delivers packets in order. A datagram network reserves nothing: each packet is routed independently, so packets may arrive out of order and the destination reorders them.

IP & IPv4

IP delivers packets between hosts using IP addresses. A packet has a header (addresses, TTL, checksum) and a payload. A router reads the destination address and consults its routing table for the next hop. An IPv4 address is 32 bits in four octets, such as 192.168.0.1, and falls into classes A–E by its first bits.

IPv6

IPv6 uses 128-bit hexadecimal addresses (eight groups separated by colons), a simpler header, traffic class and flow label for real-time traffic, and built-in security. It supports unicast, multicast and anycast, and solves IPv4 address exhaustion.

ICMP

ICMP reports errors and diagnostics for IP. Ping sends echo requests and times the replies; traceroute reveals the route. Attackers abuse it for ping floods, Smurf attacks and the ping of death.

Routing

Routing algorithms compute the least-cost path. Link-state routing floods LSAs so every router builds a full map, then runs Dijkstra’s SPF to fill its forwarding table. It converges fast but needs more memory.

RIP

RIP is a distance-vector protocol using hop count (maximum 15). Routers broadcast tables every 30 seconds; routes unrefreshed for 180 seconds are dropped. RIPv2 adds subnet masks, multicast and authentication; RIPng supports IPv6.

OSPF

OSPF is a link-state protocol inside an autonomous system. Neighbours exchange Hello packets and LSAs, then run SPF. On broadcast networks the highest priority, then highest Router ID, becomes DR; the BDR is its backup.

Select a state.

BGP

BGP routes between autonomous systems. Peers exchange reachability information and path attributes, store routes, and prefer the shortest path. EBGP links different systems; IBGP links routers within one.
